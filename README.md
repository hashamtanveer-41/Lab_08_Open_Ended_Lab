# Detective Game
# The case of Emerald heirloom


# Overview: 
This is a text based detective game comprising of 3 stages. In each stage the user who is playing as a role of detective named "Sherlock holmes" is given various choices. If the detective chooses the right choice then his reputation and score increases but if he makes a wrong decision it will cost him reputation and score.

# Game Flow: 
1. Introduction:
The game starts and in main  function the displayIntro() function is called which prints all the scenario, game instructions, objectives, characters information and location information.

 2. Main menu:
    After the introduction to game scenario the player is displayed a menu where he chooses his action.
3. Stage 1:
   From the menu user chooses the location to study room.
